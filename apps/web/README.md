# OmniDispatch 前端

一页一棵树。没有登录页、没有侧边栏、没有分页、没有表格、没有滚动。

```
apps/web/
  index.html    页面骨架
  app.css       全部样式
  app.js        取数 + 建树 + 绘制 + 一屏适配
  build.mjs     把这三个文件同步到 omnidispatch/static
```

## 构建

```
node build.mjs          # 不需要 npm install，也没有依赖
```

产物直接写进 `omnidispatch/static/`，FastAPI 以 `StaticFiles(html=True)` 挂在 `/`。

## 数据

| 树上的位置 | 数据来源 |
| --- | --- |
| 区域（六枝） | `/api/channels` 里的 `platform`，另加一支「出口与支撑」＝没有任何平台通道的来源 |
| 来源（茎上的节点） | `channel.engine`；同一引擎在多个区域出现时只首次带数字 |
| 叶（三颗点） | 该通道的三个事实：已接入（`capabilities.implemented`）、已配版本（`version`）、有上游版本（`/api/updates`） |
| 版本与时间 | `/api/updates` 里该引擎最新一条的 `version` 与 `data.published_at` |

区域占比用独立口径：`通道×1 ＋ 已接入×4 ＋ 有上游版本×3 ＋ 已配版本×2`，
与节点占比分开算、互不推导；页脚写明。主干上挂 `界面 x.x%`，极少但不为 0。

## 免登录

`/api/bootstrap`（见 `omnidispatch/app.py`）只对**本机直连**发放会话：
Host 是 `127.0.0.1/localhost`、对端是回环、且没有 `cf-*` 或 `X-Forwarded-For` 转发头。
经 Cloudflare 隧道进来的请求一律仍需口令，界面此时才显示一行口令输入框。

## 二级页

树是首页，其余全部是二级页——**同一套语法**：一根竖脊、器官挂在脊上、文字在右、动作是文字，
没有卡片、没有表格、没有弹窗。

| 地址 | 页面 | 器官 |
| --- | --- | --- |
| `#/` | 来源树 | 叶 / 花 / 果 / 枯 / 光枝 |
| `#/c/<通道>` | 通道 | 同上的器官，配版本、核验、启用、停用、优先级 |
| `#/jobs` `#/j/<id>` | 任务 | 果=成功，叶=在飞，枯=失败/待核验 |
| `#/assets` | 素材 | 水滴，直径按文件大小 |
| `#/updates` | 更新 | 幼芽：候选黄、激活绿、回滚红 |
| `#/audit` | 审计 | 年轮 |
| `#/accounts` | 账号 | 种子 |
| `#/agents` | 执行节点 | 蜂 |
| `#/settings` | 安全 | 根 |

入口：树上点叶、点左上种子、点右上蜂、点树底那排工具栏。

## 一屏

### 器官 → 通道状态（红绿灯三色）

形状说“是什么”，颜色说“能不能用”：

| 颜色 | 含义 | 器官 |
| --- | --- | --- |
| 绿 `#3E7D4F` | 通 | 果（已启用且健康） |
| 黄 `#C99A3E` | 差一步 | 花（有版本未启用）、叶（已接入未配版本） |
| 红 `#C4534E` | 通不了 | 光枝（未接入）、枯（熔断） |

每个器官外面套一圈呼吸环，**1 秒一周期**，按顺序错开相位（`animation-delay` 递减），
看起来像脉冲自上而下走一遍。系统开启“减少动态效果”时自动停。

### 两个入口也符号化了

- **账号 = 种子**（左上，红／黄）：0 个账号＝红，有账号＝黄
- **节点 = 蜂**（右上，绿／红）：有在线节点＝绿，否则红

两者都带呼吸环、都可点，分别进 `#/accounts` 和 `#/agents`——蜂是授粉者，没它花就结不了果。

### 器官 → 通道状态

| 器官 | 判定 | 详情页给什么动作 |
| --- | --- | --- |
| 果（金苹果带柄叶） | 已启用且健康 | 停用 |
| 花（玫色五瓣） | 有版本、未启用 | 记录核验、启用 |
| 叶（带主脉的叶） | 已接入、无版本 | 配版本 |
| — （光枝） | 未接入的候选 | 无 |
| 枯（萎叶） | 熔断 | 无 |
| 芽（版本号旁的小芽） | 上游版本越过本地 | 无 |

现在库里有 4 朵花、13 片叶、7 根光枝，**0 颗果**——因为还没有任何通道被启用。启用一条花（核验通过后），它就会结果。

核验要求在线节点上报同版本且 `ready`，再加一枚人工核验的真实作品 ID；不满足时接口会明确回绝，页面把它原样显示出来，不假装成功。

## 一屏

启动时二分搜索缩放系数 `k`，同时受高度与宽度约束（最宽的来源标签必须装进它那一列）。
打开 `/#dbg` 可在左下角看到实时 `view / scroll / k`。
